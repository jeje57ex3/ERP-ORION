Sécurité

Orion ERP protège les accès et centralise les données côté serveur.

Les applications PC et mobile se connectent au serveur Orion ERP via API HTTPS. Les données ERP ne quittent jamais le serveur.

🔒

HTTPS obligatoire

Toutes les communications entre applications et serveur passent par HTTPS chiffré. Aucune donnée en clair.

🎫

Sessions sécurisées

L'authentification utilise des sessions Django sécurisées. Les credentials peuvent être stockés dans le gestionnaire Windows Credential Manager.

🗄️

Données centralisées

Les données ERP restent sur le serveur. Les applications n'en stockent aucune copie locale.

🏢

Multi-entreprise isolé

Chaque entreprise dispose de ses propres données cloisonnées. Un utilisateur ne voit que ce à quoi il a accès.

🛡️

Modules par entreprise

Chaque module peut être activé ou désactivé par entreprise. Les accès sont contrôlés par rôle utilisateur.

📋

Journaux d'audit

Toutes les actions sensibles sont enregistrées dans les journaux d'audit pour traçabilité complète.
