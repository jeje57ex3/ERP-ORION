Installation Windows

Installer Orion ERP sur Windows.

Utilise l'installateur officiel Orion ERP Desktop. Compatible Windows 10 / 11 (64 bits).

Télécharger OrionERP-Desktop-Setup.exe
1

Télécharger l'installateur

Clique sur le bouton ci-dessus pour télécharger OrionERP-Desktop-Setup.exe.

2

Lancer le fichier .exe

Double-clique sur le fichier téléchargé. Si Windows SmartScreen apparaît, clique sur Informations complémentaires → Exécuter quand même.

3

Suivre l'assistant d'installation

Choisis les raccourcis souhaités (bureau, démarrage automatique), puis clique sur Installer.

4

Ouvrir et se connecter

Lance Orion ERP Desktop depuis le raccourci bureau. L'application se connecte automatiquement au serveur ERP.

Serveur par défaut

https://login.elysiums.fr

Tu peux modifier l'adresse du serveur dans les paramètres de l'application.
