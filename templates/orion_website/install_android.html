Installation Android

Installer Orion ERP sur Android.

L'application Android Orion ERP utilise un fichier APK à installer directement sur le téléphone.

Télécharger OrionERP-Mobile.apk
1

Télécharger le fichier APK

Télécharge OrionERP-Mobile-release.apk sur ton téléphone Android.

2

Autoriser les sources inconnues

Sur Android, va dans Paramètres → Sécurité → Sources inconnues (ou autorise depuis le navigateur lors de l'ouverture du fichier).

3

Ouvrir le fichier APK

Ouvre le fichier depuis les téléchargements et valide l'installation.

4

Se connecter

Lance l'application et connecte-toi avec tes identifiants Orion ERP.

Serveur : https://login.elysiums.fr

Important

Installe uniquement l'APK officiel fourni sur cette page. Ne télécharge pas l'application depuis des sources tierces.
